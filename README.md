# Trabajo Práctico Integral – Bases de Datos Aplicadas

## Altos de Saint Just – Sistema de Administración de Consorcios

Este repositorio contiene el desarrollo del **Trabajo Práctico Integral** para la materia **Bases de Datos Aplicadas**, cuyo objetivo principal es aplicar de forma práctica los conceptos teóricos aprendidos a lo largo del curso mediante el diseño y construcción de una base de datos para un sistema de gestión administrativa.

---

## 📘 Descripción del Trabajo

El proyecto consiste en el desarrollo de un sistema de base de datos para una empresa ficticia de administración de consorcios llamada **Altos de Saint Just**. Esta empresa se encarga de la gestión integral de edificios y propiedades horizontales, y el sistema busca modelar y resolver las necesidades administrativas que este tipo de organización requiere.

---

## 🎯 Objetivos del TP

* Modelar una base de datos relacional basada en requerimientos funcionales.
* Diseñar e implementar el modelo lógico y físico en **SQL Server**.
* Aplicar buenas prácticas en la normalización de datos.
* Desarrollar procedimientos almacenados, funciones, vistas, entre otros, para la gestión eficiente de los datos.
* Demostrar la capacidad de realizar consultas complejas que respondan a las necesidades informativas del sistema.

---

## 🛠️ Tecnologías utilizadas

* **SQL Server** (versión recomendada: 2019 o superior)
* **SQL** (T-SQL para procedimientos, funciones, triggers, etc.)

---

## 📁 Contenido del Repositorio

El repositorio está organizado en las siguientes carpetas:

### 📦 Carpetas por entrega

Cada entrega parcial del Trabajo Práctico cuenta con su propia carpeta, identificada como:

* `Entrega_1/`
* `Entrega_2/`
* `Entrega_3/`
* ...

Estas carpetas incluyen:

* Scripts SQL correspondientes a cada etapa (creación de tablas, carga de datos, procedimientos, consultas, etc.).
* Documentación complementaria (diagramas, explicaciones, decisiones de diseño).
* Instrucciones específicas según la consigna de la entrega.

### 🗂️ Carpeta de materiales

* `Material_TP/`: Contiene las **consignas del trabajo práctico**, **archivos provistos por la cátedra**, y otro material de referencia útil para el desarrollo del sistema.

## 🏗️ Funcionalidades principales del sistema

* Gestión de consorcios, edificios y unidades funcionales.
* Registro de propietarios e inquilinos.
* Administración de expensas, pagos y morosidad.
* Registro de proveedores y órdenes de trabajo.
* Control de gastos e ingresos por consorcio.
